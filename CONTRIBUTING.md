# CONTRIBUTING

Thanks for helping out!

This repository builds the Rouge OS images. Rouge is derived from [Bluefin](https://projectbluefin.io/) and still consumes shared tooling from [projectbluefin/common](https://github.com/projectbluefin/common); changes that belong upstream should be sent there.

For Rouge-specific contributions (branding, flatpak selection, image configuration), open an issue or PR here.
